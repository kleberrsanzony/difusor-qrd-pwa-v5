# Difusor Lab v5

PWA estática para calcular difusores Skyline 2D e QRD 1D.

## Novidade principal

A exportação PDF usa um documento A4 exclusivo:

- resumo em uma folha;
- mapa em uma folha, com ajuste automático;
- lista de peças em uma folha;
- materiais em uma folha;
- cada barrote em sua própria folha;
- montagem em uma folha.

Nenhum cartão de barrote é dividido entre páginas.

## Rodar localmente

```bash
python3 -m http.server 8080
```

Abra `http://localhost:8080`.
